❓ API Key എങ്ങനെ ലഭിക്കും?

  1. Google AI Studio സന്ദർശിക്കുക.
  2. നിങ്ങളുടെ Google Account വഴി ലോഗിൻ ചെയ്യുക.
  3. "Create API Key" എന്ന ബട്ടൺ ക്ലിക്ക് ചെയ്യുക.
  4. ലഭിക്കുന്ന Key കോപ്പി ചെയ്ത് മുകളിലെ ബോക്സിൽ നൽകുക. (ഇത് തികച്ചും സൗജന്യമാണ്).
