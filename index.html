1 Gemini API കീ

എങ്ങനെ ഉപയോഗിക്കാം:
  1. താഴെ നിങ്ങളുടെ Gemini API കീ നൽകി "സേവ് ചെയ്യുക" അമർത്തുക.
  2. കീ ഒരിക്കൽ സേവ് ചെയ്താൽ ഈ ബ്രൗസറിൽ സൂക്ഷിക്കും — വീണ്ടും ചോദിക്കില്ല, അടുത്ത തവണ നേരിട്ട് കത്ത് തയ്യാറാക്കൽ പേജിലേക്ക് പോകും.
  3. അതിനുശേഷം മാത്രം താഴെയുള്ള ഭാഗങ്ങൾ (രേഖയുടെ തരം, വിവരങ്ങൾ മുതലായവ) ദൃശ്യമാകും.
API കീ എങ്ങനെ കിട്ടും: Google AI Studio-യിൽ Google അക്കൗണ്ട് ഉപയോഗിച്ച് ലോഗിൻ ചെയ്ത് "Create API key" അമർത്തിയാൽ സൗജന്യമായി കീ ലഭിക്കും.
Error വന്നാൽ ഈ പേര് പുതിയ മോഡൽ പേരാക്കി മാറ്റി നോക്കുക (ഉദാ: gemini-2.5-flash).
API കീ ശരിയായി സേവ് ചെയ്തിട്ടുണ്ട്. കീ മാറ്റണോ?
